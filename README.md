# Detection of AI-Generated Arabic Text: A Data Mining Approach

## Project Overview
This project aims to detect whether Arabic text is human-written or AI-generated using data mining and machine learning techniques.

## Dataset
KFUPM-JRCAI/arabic-generated-abstracts (Hugging Face)

## Project Structure
- data: Dataset files
- notebooks: Jupyter notebooks
- src: Python source code
- models: Trained models
- reports: Results and reports
